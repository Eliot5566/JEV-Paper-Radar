TraceGrade: Evaluating LLM Agents on Long-Horizon Tool-Use Tasks with Step-Level Verification

Mira Okafor, Tomás Lindqvist, Hae-won Seo et al. · cs.CL, cs.AI

Agent evaluation 95%
Abstract

Benchmarks for LLM agents usually score only the final answer of a multi-step episode. We introduce TraceGrade, a benchmark of 1,240 multi-step tool-use tasks across web, shell, and spreadsheet environments in which every intermediate action is verified against an executable checker. Evaluating 14 LLM agents, we find that final-answer accuracy overstates step-level correctness by up to 31 points. Code and tasks are publicly released.

Abstract

ToolBench Mini: Evaluating Repeated Tool Calls

直接命中：摘要提出評測 LLM agent 規劃與執行多步工具呼叫的 benchmark，含失敗工具復原，並報告完成率與錯誤復原指標。

Abstract

We introduce a benchmark for LLM agents that must plan and execute sequences of tool calls. Tasks require retrieving information, checking intermediate results and recovering from a failed tool. We report completion rate and error recovery across several agent policies.

KV Compression for Long-Context Inference

僅與 LLM 相關：主題是長上下文推論的 KV 快取壓縮，評估記憶體、延遲與模型品質；摘要明言未提出工具型 agent 的 benchmark。

Abstract

We compress the key-value cache used by a language model during long-context inference. Evaluation measures memory savings, latency and language-model quality. The method does not introduce a benchmark for tool-using agents.

Before your first run

Know what you are getting.

Do I need an API key?

No separate model API key for conversational retrieval, ranking or exports. Normal Claude plan usage applies. Retrieval makes public metadata requests and needs permitted network or existing web tools. Scheduled model API judging is separately billed.

Does installation start a daily radar?

No. You can request a single search in the current conversation. Daily schedules, long-term storage and publishing still need separate setup.

Is a score of 0.93 a 93% chance of relevance?

No. Claude's scores are self-reported and uncalibrated. Label selected and unselected papers yourself, fit thresholds on one batch and evaluate on a separate later batch.

What has actually been checked?

Claude web Opus 5.5 loaded the bundle, checked its file hashes and exported reports. The 0.2.0 link test retrieved two real papers through existing Claude web tools after the metadata API was blocked; summaries were labelled. Local tests: 250; Python 3.11–3.13 CI passed. Functional checks do not establish accuracy or every-client compatibility.

What should I share when something goes wrong?

Your environment, package version, the step that failed and a redacted error. Do not post keys, private abstracts or unpublished research. A first-run report is more useful than a star.
